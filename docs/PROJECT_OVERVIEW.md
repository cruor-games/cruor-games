# Cruor Games — Project Overview

Cruor Games is a modular web platform for tabletop RPG tools, dark fantasy generators, interactive dossiers, maps, and campaign-support utilities.

The application should be structured as a collection of independent features sharing a common shell, visual language, and data conventions.

Current main features:

- Darken a Location
- Map Generator
- Future dossier/library tools
- Future campaign/content tools

The map generator must integrate with Darken a Location but remain reusable as an independent module.
